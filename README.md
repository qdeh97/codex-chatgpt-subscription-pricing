## 先确认：Codex 没有单独的「会员」，它跟着 ChatGPT 订阅走

这一点没搞清就下单，很容易买错东西。

按 OpenAI 目前的产品说明，Codex 包含在 ChatGPT 的 Plus、Pro、Business、Edu 和 Enterprise 方案里，不单独售卖。你也可以用 API Key 走按量计费，但那是完全另一条路。所以「国内购买 Codex」翻译成操作层面，其实只有两个选项：

## 国内付款卡在哪：三道门槛，一个比一个难绕

第一道是网络。Codex 的登录授权要走 OpenAI 的验证流程，桌面端和 CLI 都需要稳定的海外线路，公司网络环境下还经常被安全策略拦掉。

第二道是账号。注册要海外手机号验证，风控这几年明显收紧。V2EX 上关于「买的号用几天就被封」的帖子从年初排到年中，讨论的重点早就不在怎么买，而在买了能撑几天。

第三道就是支付，也是搜索「Codex 国内购买」的人最想解决的问题：能付美元的卡开不出来，开得出来的虚拟卡又随时可能被风控。

## 几个常被问到的问题

**用自己的账号代充会封号吗？** 没有公开资料能给出保证。风险主要来自账号本身的行为和节点纯净度，官方自购也一样有风控。共用同一个账号的那种便宜方案，封号概率明显更高。

**代充和自己买差别在哪？** 账号归属。代充开在你自己的账号上，记录和登录设备都保留；成品号到手就是一个陌生账号，哪天失效都不通知你。

**多久能到账？** 正常情况下订单处理是自动的，几分钟到十几分钟属于常见范围。遇到人工介入的异常订单会明显变慢，这也是上面强调要留凭证的原因。

**续费要自己操作吗？** 不要指望自动续费永远不出问题，上面的记录里已经出现过付款方式失效导致续订中断的情况。到期前主动检查一次账号状态，比事后找客服省事。
